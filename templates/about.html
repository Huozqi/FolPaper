FolPaper

一站式智能学术文献追踪、筛选与阅读管理平台

FolPaper 聚合 RSS、PubMed、arXiv、OpenAlex、Crossref 五大数据源，集成 Patchright 引擎绕过 Cloudflare 反爬，配合三级 API 补源链与 AI 大语言模型，实现文献抓取、翻译、推荐、归档全流程自动化。

智能抓取引擎

直连 → Cookie 预取 → Patchright 反检测浏览器三级级联，绕过 Cloudflare/Akamai 安全验证。被拦截时自动启动 Crossref → PubMed → OpenAlex 三级 API 补源，文献零丢失。

🧠

AI 辅助分析

标题与摘要翻译、自然语言智能筛选、AI 背景调研报告生成，支持 OpenAI 兼容 API，可接入任意大语言模型。

📦

桌面应用体验

基于 pywebview 的原生桌面窗口。双击启动，无浏览器依赖。同时支持 Web 模式便于远程访问和开发调试。
